# 类和对象：课时三

上一课时讨论了构造、析构、拷贝构造和赋值，也通过日期类实现了一组运算符。本课时接着观察取地址运算符，再讨论友元函数、构造函数的初始化列表，以及构造函数参与类型转换时的行为。

## 取地址运算符重载

对于普通对象，`&d` 得到指向该对象的指针；对于常对象，得到的指针还要保留所指对象的常量性：

```cpp
wind::Date d(2024, 10, 1);
const wind::Date cd(2024, 10, 1);

wind::Date* p = &d;
const wind::Date* cp = &cd;
```

类可以重载一元取地址运算符，并提供普通成员函数与常成员函数两个版本。若只是返回对象自身的地址，可以写成：

```cpp
// Date 类中的声明。
Date* operator&();
const Date* operator&() const;

// 类外定义。
wind::Date* wind::Date::operator&()
{
    return this;
}

const wind::Date* wind::Date::operator&() const
{
    return this;
}
```

普通版本中的 `this` 是 `Date*`，常版本中的 `this` 是 `const Date*`，所以返回类型与各自的访问权限相符。不能让常对象通过取地址得到可修改它的普通指针。

有些教材将这两个版本与前面四项并列，称为“六个默认成员函数”。这里需要区分语言提供的默认取地址行为与自动生成成员函数：没有重载时，`&d` 可以直接使用内建取地址运算，并不是编译器一定生成了可供调用的 `Date::operator&()`。

通常没有必要自己重载这两个函数，直接使用内建取地址即可。只有确实需要为取地址操作设计特殊含义时，才考虑提供重载；本节只是借它们观察普通对象与常对象对应的两种接口。

## 友元函数

### 从流插入与流提取说起

对于整数，可以用 `std::cout << i` 输出，也可以用 `std::cin >> i` 输入。`std::cout` 与 `std::cin` 都是标准库提供的对象，类型分别为 `std::ostream` 和 `std::istream`。流类型与相关非成员函数提供了多组运算符重载，使不同类型的数据可以采用相近的输入输出形式。

日期类也可以支持相同的用法：

```cpp
wind::Date d(2024, 10, 1);
std::cout << d;
std::cin >> d;
```

但 `operator<<` 不能简单地写成 `Date` 的成员函数。对于成员形式的二元运算符，左操作数是调用该成员函数的对象。若把它定义在 `Date` 中，得到的自然形式会是 `d << out`，而我们需要的是 `out << d`，左侧是流对象。

因此，将它定义为非成员函数，显式接收两个操作数：输出流和日期对象。输入运算符同理，接收输入流和要修改的日期对象。

非成员函数不能直接访问 `Date` 的私有成员。如果希望它直接读取或修改年月日，可以在 `Date` 类中用 `friend` 声明它为友元。友元函数仍然是非成员函数，不具有 `Date` 成员函数的隐含 `this` 参数；它获得的是访问该类私有成员的权限。

友元声明放在类体的 `public`、`private` 或 `protected` 区域都可以，不受这些访问限定符影响。下面保留与本节有关的接口，上一课时的日期运算成员可以继续保留，不必为输入输出重新设计。

```cpp
// Date.h
#pragma once
#include <iostream>

namespace wind
{
    int DayList(int year, int month);

    class Date
    {
        friend std::ostream& operator<<(std::ostream& out, const Date& d);
        friend std::istream& operator>>(std::istream& in, Date& d);

    public:
        Date();
        Date(int year, int month, int day);
        void Print() const;

        // 上一课时的日期运算成员可以继续放在这里。

    private:
        int _year;
        int _month;
        int _day;
    };
}
```

这里取消三个参数全部带缺省值的构造函数，分别提供两个版本：无参构造取得当前本地日期；三参数构造创建指定日期。如果仍保留原先的全缺省版本，再增加 `Date()`，无实参调用就会同时匹配两个版本，产生二义性。

### 无参构造取得当前本地日期

一次取得时间，再从同一份本地时间中取出年月日：

```cpp
// Date.cpp
#include "Date.h"
#include <chrono>
#include <ctime>

wind::Date::Date()
{
    auto now = std::chrono::system_clock::now();
    std::time_t timestamp = std::chrono::system_clock::to_time_t(now);
    std::tm* result = std::localtime(&timestamp);

    if (result == nullptr)
    {
        std::cout << "错误：无法取得当前本地日期！" << std::endl;
        _year = _month = _day = 1;
        return;
    }

    std::tm local = *result;
    _year = local.tm_year + 1900;
    _month = local.tm_mon + 1;
    _day = local.tm_mday;
}

wind::Date::Date(int year, int month, int day)
{
    if (year < 1 || month < 1 || month > 12 ||
        day < 1 || day > DayList(year, month))
    {
        std::cout << "错误：非法的日期参数！" << std::endl;
    }

    _year = year;
    _month = month;
    _day = day;
}
```

`system_clock::now()` 读取当前系统时间，`to_time_t` 将它转换成时间库使用的表示，`std::localtime` 再按运行环境的本地时区转换成日历字段。`tm_year` 从 1900 年起计数，`tm_mon` 从 0 开始计数，因此分别加上 1900 和 1；`tm_mday` 本来就是本月日号。

这份单线程示例使用标准库的 `std::localtime`，并立即复制它返回的结果。年月日来自同一次时间读取，不会因三次分别读取刚好跨过午夜而拼出不一致的日期。

若转换失败，当前示例打印提示并使用 `1/1/1` 作为回退值。带参构造仍沿用上一课时的处理：检查失败只提示，并保留传入值；正常日期运算继续以合法日期为前提。

`DayList` 沿用上一课时的月份天数规则：

```cpp
int wind::DayList(int year, int month)
{
    const static int days[13] =
        { 0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };

    // 调用者应先确认年份和月份合法。
    if (month == 2 &&
        (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)))
    {
        return 29;
    }
    return days[month];
}
```

### 输入输出运算符的实现

输出只需要读取日期，所以日期形参使用常引用；输入需要修改日期，所以使用普通引用。两个函数都返回原来的流对象引用，使连续输入输出能够继续进行：

```cpp
// Date.cpp 中的非成员函数定义。
namespace wind
{
    std::ostream& operator<<(std::ostream& out, const Date& d)
    {
        out << d._year << "/" << d._month << "/" << d._day;
        return out;
    }

    std::istream& operator>>(std::istream& in, Date& d)
    {
        int year;
        int month;
        int day;

        // 若没有完整读入三个整数，保留原日期并返回输入流。
        if (!(in >> year >> month >> day))
            return in;

        if (year < 1 || month < 1 || month > 12 ||
            day < 1 || day > DayList(year, month))
        {
            std::cout << "错误：非法的日期参数！" << std::endl;
        }

        d._year = year;
        d._month = month;
        d._day = day;
        return in;
    }
}

void wind::Date::Print() const
{
    std::cout << *this << std::endl;
}
```

友元声明虽然写在类体中，函数定义仍位于 `wind` 命名空间，不能把它写成 `Date::operator<<`。

`out << d1 << d2` 按左结合求值，先得到 `out << d1` 返回的流引用，再继续输出 `d2`。输入运算符返回 `in` 也是同样的道理。

输入时先用局部变量接收三个整数，只有完整读取后才写入日期成员。对于完整读入但不符合日期模型的数据，仍沿用打印提示、保留输入的教学处理。这里输入格式是三个以空白分隔的整数，不要求输入 `/`。

### 从流状态检查认识类型转换函数

输入代码中还有一个问题需要说明：`in >> year >> month >> day` 返回的是输入流引用，为什么它还能用于条件判断？

类可以定义类型转换函数，说明对象怎样转换为另一种类型。它的名字写成 `operator 目标类型`，没有显式参数，也不另写返回类型，因为目标类型已经写在函数名中。例如：

```cpp
class ReadState
{
public:
    ReadState(bool ok)
        : _ok(ok)
    {}

    operator bool() const
    {
        return _ok;
    }

private:
    bool _ok;
};

void CheckState()
{
    ReadState state(true);
    if (state)
    {
        std::cout << "状态正常" << std::endl;
    }
}
```

这里的 `operator bool()` 是成员函数，可以通过当前对象的 `_ok` 得到转换结果。与前面通过构造函数把其他类型转换成类对象相比，这次是在说明类对象怎样转换成 `bool`。

标准流也提供了到 `bool` 的转换。对于 `if (std::cin >> d)`，先执行日期输入，得到返回的输入流，再根据流的状态决定条件是否成立。出现格式不匹配、读入失败等状态时，条件为假；正常完成读取时，条件为真。前面检查日期是否合法时只是打印提示，没有修改流的错误状态，因此这项判断只说明流读取是否成功，不代表日期一定符合日历规则。

C++11 中，标准流的这一转换带有 `explicit` 限定，但仍允许用于 `if` 等明确需要布尔条件的地方。`explicit` 对隐式转换的限制会在后文结合构造函数介绍。

前面的 `if (!(in >> year >> month >> day))` 还多了一层取反。标准流本身提供了 `operator!()`，用于判断流是否处于失败状态，因此这里走的并非 `operator bool()`。两种写法表达的意图一致：读入成功才继续处理，读入失败就停止本次修改。

现在测试输入输出，无参构造直接取得当天日期：

```cpp
// main.cpp
#include "Date.h"
#include <iostream>

void test6()
{
    wind::Date d;
    std::cout << d << std::endl;

    std::cout << "请输入年、月、日，以空格分隔：";
    // 提取运算返回输入流，再根据流的状态判断是否继续。
    if (std::cin >> d)
        std::cout << d << std::endl;
}

int main()
{
    test6();
    return 0;
}
```

## 初始化列表

### 初始化发生在函数体之前

前面把年月日写入成员时，一直使用构造函数体中的赋值。现在补上构造函数的另一部分：成员初始化列表。

创建对象时，在进入构造函数体之前，成员的初始化阶段就已经进行。初始化列表让我们明确指定各个成员在这一阶段使用的值。等进入函数体，再对已经初始化的成员使用 `=`，就是赋值。

成员本身仍在类定义中声明。初始化列表描述的是怎样初始化成员。

写法是在构造函数参数列表之后、函数体之前加一个冒号，再用逗号分隔各成员的初始化项：

```cpp
wind::Date::Date(int year, int month, int day)
    : _year(year), _month(month), _day(day)
{
    if (year < 1 || month < 1 || month > 12 ||
        day < 1 || day > DayList(year, month))
    {
        std::cout << "错误：非法的日期参数！" << std::endl;
    }
}
```

这个版本用于替换前面的三参数构造。`_year(year)` 表示使用形参 `year` 初始化成员 `_year`，另外两个成员同理。日期检查仍留在函数体中，因此进入检查时，三个成员已经完成初始化。

对于这些简单整数，函数体赋值和直接初始化可能生成相近的机器指令，但语言层面的步骤不同。遇到必须在初始化时确定状态的成员，这一区别就不能忽略。

### const 成员与引用成员

常量成员需要在初始化时确定值；引用成员需要在初始化时确定所绑定的对象。等进入构造函数体，再给常量赋值或试图让尚未绑定的引用建立绑定，就已经晚了。

下面的类同时包含这两种成员：

```cpp
#include <iostream>

namespace wind
{
    class A
    {
        friend std::ostream& operator<<(std::ostream& out, const A& value);

    public:
        A(int i, int& j);
        void F();

    private:
        const int _a;
        int& _b;
    };

    std::ostream& operator<<(std::ostream& out, const A& value)
    {
        out << value._a << " " << value._b;
        return out;
    }
}

wind::A::A(int i, int& j)
    : _a(i), _b(j)
{}

void wind::A::F()
{
    ++_b;
}

int main()
{
    int k = 0;
    wind::A value(10, k);
    value.F();
    std::cout << k << std::endl;     // 1
    std::cout << value << std::endl; // 10 1
}
```

`_a` 初始化为 10，`_b` 绑定到 `k`。随后执行 `++_b`，修改的就是 `k`。如果在函数体里写 `_b = j`，它表达的是向引用已经绑定的对象赋值，并不是重新建立引用绑定。

对于这里的类定义，这两个成员都必须在进入构造函数体之前完成初始化：`const` 成员一旦初始化就不能再赋值，引用成员一旦绑定也不能再改为绑定其他对象。因此，应在初始化列表中给 `_a` 指定初始值、给 `_b` 指定绑定对象，不能把这些工作留到函数体中。

### 没有默认构造函数的成员对象

成员本身是类对象时，也需要在进入外层构造函数体之前完成构造。若该成员类型没有可无参调用的构造函数，就需要为它提供参数。

沿用刚才的 `A`，再定义一个包含 `A` 对象的 `B`：

```cpp
// 假设 A 的声明位于 A.h，定义已在对应源文件中提供。
#include "A.h"

namespace wind
{
    class B
    {
    public:
        B(int& n, int c);

    private:
        A _i;
        int _j = 4;
        int _k = 6;
        int _m;
    };
}

wind::B::B(int& n, int c)
    : _i(5, n), _m(10)
{
    _m = c;
}

int main()
{
    int k = 0;
    wind::B x(k, 15);
}
```

`A` 只有需要两个参数的构造函数，不能无参构造，因此这里通过 `_i(5, n)` 指定它的构造参数。

这一例中，各成员在进入 `B` 构造函数体之前的状态如下：

| 成员 | 初始化来源                | 结果                                                  |
| ---- | ------------------------- | ----------------------------------------------------- |
| `_i` | 初始化列表中的 `_i(5, n)` | 调用 `A` 的构造函数，常量成员取 5，引用成员绑定到 n。 |
| `_j` | 类内默认初始值            | 4。                                                   |
| `_k` | 类内默认初始值            | 6。                                                   |
| `_m` | 初始化列表中的 `_m(10)`   | 10。                                                  |

随后才执行函数体里的 `_m = c`，把已经初始化为 10 的成员改为 15。这样就能对照观察“先初始化，再赋值”的两个阶段。

### 初始化顺序由成员声明顺序决定

成员的初始化顺序由它们在类中的声明顺序决定，与初始化列表的书写顺序无关。在刚才的 `B` 中，依次是 `_i`、`_j`、`_k`、`_m`。初始化列表即使没有列出所有成员，也不会跳过其余成员应有的初始化步骤。

写代码时，初始化列表最好也按成员声明顺序排列，避免文字顺序与实际执行顺序不一致，尤其不要用尚未初始化的后置成员去初始化前面的成员。

还可以把当前阶段的规则归纳为：

- 初始化列表显式列出的成员，使用该项指定的初始化方式；若它同时具有类内默认初始值，这次以初始化列表为准。
- 没有显式列出、但有类内默认初始值的成员，使用该默认值。
- 两处都没有提供初始值时，类类型成员尝试默认构造；当前例子中的普通整数成员不会因此自动取得确定的初始值。

自己编写初始化列表，并不会使其他成员的默认初始化规则失效。编译器提供的默认构造函数同样需要遵守成员初始化规则，不能仅因为看不到函数体里的代码，就认为它对所有成员都什么也不做。

拷贝构造也是构造函数，同样可以使用初始化列表。例如，日期类可以这样复制三个成员：

```cpp
// Date 类中先声明 Date(const Date& d);。
wind::Date::Date(const Date& d)
    : _year(d._year), _month(d._month), _day(d._day)
{}
```

## 隐式类型转换

### 从内置类型到类类型

先看已经熟悉的内置类型转换：

```cpp
float i = 1.25f;
int j = i; // 得到 1，小数部分被舍弃。
```

这里先把 `i` 中的浮点数值转换为整数值 1，再用这个转换结果初始化 `j`。可以把转换结果理解为连接源值与目标变量的中间值。

类类型也可以通过合适的构造函数接受其他类型的值。下面为 `C` 显式提供拷贝构造函数，便于联系临时对象与复制的过程：

```cpp
namespace wind
{
    class C
    {
    public:
        C(int i);
        C(const C& c);

    private:
        int _i;
    };
}

wind::C::C(int i)
    : _i(i)
{}

wind::C::C(const C& c)
    : _i(c._i)
{}

int main()
{
    wind::C m1(1);
    wind::C m2 = 2;
}
```

`m1(1)` 直接调用构造函数。`m2 = 2` 则让整数 2 通过 `C(int)` 转换为 `C`，用来初始化新对象。这种写法称为拷贝初始化：虽然写有 `=`，但 `m2` 正在创建，并不是在调用赋值拷贝。

这种转换也可以出现在传参时：

```cpp
void Use(const wind::C& value)
{
    // 使用 value。
    (void)value;
}

Use(2); // 通过 C(int) 构造一个临时 C，供形参引用。
```

### 多参数构造与列表初始化

C++11 起可以使用花括号提供多个初始化项。对于下面的类：

```cpp
namespace wind
{
    class D
    {
    public:
        D(int i, int j);

    private:
        int _i;
        int _j;
    };
}

wind::D::D(int i, int j)
    : _i(i), _j(j)
{}

int main()
{
    wind::D n1(1, 2);
    wind::D n2 = { 1, 2 };
    wind::D n3{ 1, 2 };
}
```

`n2` 使用拷贝列表初始化，花括号中的两项用来选择并调用 `D(int, int)`；`n3` 则使用直接列表初始化。

当前先记住两种花括号写法都能给构造函数提供多个参数，接下来通过 `explicit` 看它们的区别，不必在此展开所有列表初始化规则。

### explicit 限制隐式转换

前面在流状态判断中已经遇到 `explicit`。现在通过构造函数观察它怎样限制隐式转换。

如果不希望单个整数自动转换为 `C`，可以把类内构造函数声明改为：

```cpp
explicit C(int i);

// 随后这些写法的含义不同。
wind::C a(1);     // 可以：直接初始化。
wind::C b{ 1 };   // 可以：直接列表初始化。
// wind::C c = 1; // 不可以：需要被 explicit 限制的隐式转换。
// Use(1);       // 不可以：不再隐式构造 C。
Use(wind::C(1));  // 可以：明确构造后传入。
```

对于双参数构造，也可以使用 `explicit`：

```cpp
namespace wind
{
    class D
    {
    public:
        explicit D(int i, int j);

    private:
        int _i;
        int _j;
    };
}

wind::D::D(int i, int j)
    : _i(i), _j(j)
{}

int main()
{
    wind::D a(1, 2);       // 可以。
    wind::D b{ 1, 2 };     // 可以。
    // wind::D c = {1, 2}; // 不可以：拷贝列表初始化不能选用此显式构造。
}
```

`explicit` 写在类内的构造函数声明处，不在类外定义时重复添加。它要求调用者明确写出构造意图，避免在传参或初始化等位置发生未预期的类型转换。

如果某个接口原本接收 `D`，未加 `explicit` 时可能允许 `UseD({1, 2})`；加上后可以改写为 `UseD(wind::D(1, 2))`。

## 匿名对象与临时对象

可以直接写出构造表达式，而不为对象指定变量名：

```cpp
wind::D(1, 2);
```

这种写法通常称为创建匿名对象。它产生一个临时对象，随后在这条完整表达式结束时销毁。对于这里的独立表达式语句，结束位置就是分号，而不是排版意义上的“这一行”；一条语句可以跨很多行。

临时对象适合一次性的传参或输出：

```cpp
void UseD(const wind::D& value)
{
    (void)value;
}

// 在函数体中使用：
UseD(wind::D(1, 2));
std::cout << wind::Date(2024, 10, 1) << std::endl;
```

第一个表达式明确构造 `D`，即使其构造函数带有 `explicit` 也可以使用。临时对象在调用期间有效，函数返回后，到这条完整表达式结束时销毁。

第二个表达式创建一个临时日期并立刻输出，不需要为了打印一次而单独起一个变量名。

临时对象的生命周期还有可以延长的情形。例如，直接绑定到局部常引用：

```cpp
const wind::D& value = wind::D(1, 2);
```

这里临时对象会存活到该引用的生命周期结束，不能再按“分号处立即销毁”来判断。当前只需要把这个直接绑定情形与前面的函数传参区分开，不将生命周期延长推广到所有引用使用方式。
